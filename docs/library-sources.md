## Cambios y disponibilidad

Los enlaces se almacenan sin repetirse y se comprueban antes de publicar. Los rechazados se revisan de nuevo en turnos posteriores. Dos candidatos por turno acotan las solicitudes; una cola grande requiere varios turnos. Alcanzar el límite diario no detiene el descubrimiento.

Se exigen HTTPS y hosts configurados, incluidas redirecciones. Los PDF deben responder como PDF; los datos deben declarar archivos públicos. No se usan sesiones ni mecanismos para saltar restricciones. HTTP 403, CAPTCHA, cambios de estructura o evidencia incompleta provocan omisión y registro del resultado.

Los materiales permanentes no se presentan como recién publicados. Se verifica disponibilidad o inscripción vigente; las noticias conservan el filtro de 48 horas.
